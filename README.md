# 🤖 AI Resume Analyzer

An AI-powered Resume Analyzer built with React and FastAPI that analyzes resumes, provides an ATS score, summarizes strengths, identifies missing skills, and suggests improvements using DeepSeek AI via OpenRouter.

## 🚀 Features

- 📄 Upload PDF resumes
- 🤖 AI-powered resume analysis
- 📊 ATS Score
- 💡 Skill gap analysis
- 📝 Resume summary
- ⚡ Fast React + FastAPI architecture

## 🛠️ Tech Stack

### Frontend
- React
- Axios
- React Markdown
- React Circular Progressbar

### Backend
- FastAPI
- Python
- PyMuPDF
- OpenRouter API
- DeepSeek AI

## ▶️ Run the Project

### Backend

```bash
cd backend
uvicorn main:app --reload
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
